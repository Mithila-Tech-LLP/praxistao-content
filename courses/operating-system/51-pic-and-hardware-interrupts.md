# Chapter 51: PIC and Hardware Interrupts

> **"Hardware interrupts are how the outside world talks to your kernel. When a key is pressed or the timer fires, the hardware sends an electrical signal to the CPU, which pauses whatever it's doing and calls your handler. Without IRQs, your OS would be deaf — it could never respond to keyboard input, never track time, never know when disk I/O finishes."**

## 1. Hardware Interrupts vs Exceptions

```
Exceptions (vectors 0-31):
  Generated by CPU itself when something goes wrong
  Synchronous: happen as a result of an instruction
  Example: divide by zero, page fault, invalid opcode

Hardware Interrupts (vectors 32-255 after remapping):
  Generated by hardware devices via the PIC chip
  Asynchronous: can happen ANY time (between any two instructions)
  Example: keyboard press, timer tick, network packet arrives
  
Software Interrupts (int $N instruction):
  Generated by software on purpose
  Used for system calls: int $0x80 (Linux) or int $0x30 (our OS)
  Synchronous: programmer controlled
```

## 2. The 8259 PIC — Programmable Interrupt Controller

The Intel 8259 PIC sits between hardware devices and the CPU:

```
Hardware device → PIC → CPU

PIC chain (two chips):
  Master PIC: handles IRQ0-IRQ7
    IRQ0: PIT (Programmable Interval Timer) — system clock tick
    IRQ1: PS/2 Keyboard
    IRQ2: Cascaded to Slave PIC
    IRQ3: COM2 serial port
    IRQ4: COM1 serial port
    IRQ5: LPT2 parallel port (or sound card)
    IRQ6: Floppy disk controller
    IRQ7: LPT1 parallel port (printer)
    
  Slave PIC (cascaded through IRQ2): handles IRQ8-IRQ15
    IRQ8:  Real-time clock (RTC)
    IRQ9:  ACPI / available
    IRQ10: Available / network card
    IRQ11: Available / USB
    IRQ12: PS/2 Mouse
    IRQ13: FPU/Coprocessor
    IRQ14: Primary ATA disk (IDE)
    IRQ15: Secondary ATA disk (IDE)

PIC I/O ports:
  Master: command = 0x20, data = 0x21
  Slave:  command = 0xA0, data = 0xA1
```

**The problem: default PIC mapping conflicts with exceptions!**

By default after BIOS:
```
IRQ0-7  → vectors 0x08-0x0F  ← CONFLICT with CPU exceptions (0-31)!
IRQ8-15 → vectors 0x70-0x77

Example: IRQ0 fires → CPU calls vector 8 handler → THAT'S the Double Fault handler!
→ System crashes or behaves erratically
```

**Solution: remap the PIC.**

## 3. Remapping the PIC

We reprogram the PIC to use vectors 32-47 (0x20-0x2F):

```c
/* kernel/pic.c — PIC driver */

#include "pic.h"
#include "io.h"     /* outb, inb */

#define PIC1_CMD   0x20
#define PIC1_DATA  0x21
#define PIC2_CMD   0xA0
#define PIC2_DATA  0xA1

#define ICW1_INIT  0x10   /* Required initialization flag */
#define ICW1_ICW4  0x01   /* ICW4 will be sent */
#define ICW4_8086  0x01   /* 8086/88 (MCS-80/85) mode */

/* PIC IRQ base vectors after remapping: */
#define PIC1_OFFSET  0x20   /* IRQ0  → vector 32 */
#define PIC2_OFFSET  0x28   /* IRQ8  → vector 40 */

/* Small I/O delay (read from port 0x80 — unused port): */
static inline void io_wait(void) {
    outb(0x80, 0x00);
}

void pic_init(void) {
    /* Save current masks (to restore them after init): */
    uint8_t mask1 = inb(PIC1_DATA);
    uint8_t mask2 = inb(PIC2_DATA);
    
    /* --- Initialization Command Word 1 (ICW1) --- */
    /* Tell both PICs we're starting initialization: */
    outb(PIC1_CMD,  ICW1_INIT | ICW1_ICW4);   /* Start init, expect ICW4 */
    io_wait();
    outb(PIC2_CMD,  ICW1_INIT | ICW1_ICW4);
    io_wait();
    
    /* --- ICW2: Set vector offsets --- */
    outb(PIC1_DATA, PIC1_OFFSET);   /* Master: IRQ0 → vector 0x20 (32) */
    io_wait();
    outb(PIC2_DATA, PIC2_OFFSET);   /* Slave:  IRQ8 → vector 0x28 (40) */
    io_wait();
    
    /* --- ICW3: Configure cascading --- */
    outb(PIC1_DATA, 0x04);   /* Master: slave PIC connected at IRQ2 (bit 2 set) */
    io_wait();
    outb(PIC2_DATA, 0x02);   /* Slave: slave cascade identity = 2 */
    io_wait();
    
    /* --- ICW4: Set mode --- */
    outb(PIC1_DATA, ICW4_8086);   /* 8086 mode */
    io_wait();
    outb(PIC2_DATA, ICW4_8086);
    io_wait();
    
    /* Restore saved masks: */
    outb(PIC1_DATA, mask1);
    outb(PIC2_DATA, mask2);
}

/* Send End of Interrupt signal: */
void pic_eoi(uint8_t irq) {
    if (irq >= 8) {
        outb(PIC2_CMD, 0x20);   /* EOI to slave PIC */
    }
    outb(PIC1_CMD, 0x20);       /* EOI to master PIC (always) */
}

/* Mask (disable) an IRQ: */
void pic_mask_irq(uint8_t irq) {
    uint16_t port = (irq < 8) ? PIC1_DATA : PIC2_DATA;
    uint8_t bit   = irq % 8;
    outb(port, inb(port) | (1 << bit));
}

/* Unmask (enable) an IRQ: */
void pic_unmask_irq(uint8_t irq) {
    uint16_t port = (irq < 8) ? PIC1_DATA : PIC2_DATA;
    uint8_t bit   = irq % 8;
    outb(port, inb(port) & ~(1 << bit));
}

/* Mask all IRQs (disable all hardware interrupts): */
void pic_disable(void) {
    outb(PIC1_DATA, 0xFF);
    outb(PIC2_DATA, 0xFF);
}
```

## 4. IRQ Stubs in Assembly

Just like exception stubs, we need assembly entry points for IRQs. We add them to `isr_stubs.asm`:

```nasm
; In boot/isr_stubs.asm — add after the exception stubs:

[EXTERN irq_handler]

; Macro for IRQ handlers (no error code, push IRQ number):
%macro IRQ 2          ; %1 = IRQ number, %2 = interrupt vector (32 + IRQ number)
[GLOBAL irq%1]
irq%1:
    push byte 0       ; Dummy error code
    push byte %2      ; Interrupt vector number
    jmp irq_common_stub
%endmacro

IRQ  0, 32    ; Timer
IRQ  1, 33    ; Keyboard
IRQ  2, 34    ; Cascade (shouldn't fire)
IRQ  3, 35    ; COM2
IRQ  4, 36    ; COM1
IRQ  5, 37    ; LPT2
IRQ  6, 38    ; Floppy
IRQ  7, 39    ; LPT1 / Spurious
IRQ  8, 40    ; RTC
IRQ  9, 41
IRQ 10, 42
IRQ 11, 43
IRQ 12, 44    ; PS/2 Mouse
IRQ 13, 45    ; FPU
IRQ 14, 46    ; Primary ATA
IRQ 15, 47    ; Secondary ATA

irq_common_stub:
    pusha
    push ds
    push es
    push fs
    push gs
    mov ax, 0x10
    mov ds, ax
    mov es, ax
    mov fs, ax
    mov gs, ax
    
    push esp
    call irq_handler
    add esp, 4
    
    pop gs
    pop fs
    pop es
    pop ds
    popa
    add esp, 8      ; Remove error code and vector number
    iret
```

Install IRQ gates in `idt_init`:
```c
/* In idt.c, after the exception gates: */
extern void irq0(void); extern void irq1(void); /* ... irq15 */

/* IRQ gates: DPL=0, Interrupt gate (0x8E): */
idt_set_gate(32, irq0,  GDT_KERNEL_CODE, 0x8E);
idt_set_gate(33, irq1,  GDT_KERNEL_CODE, 0x8E);
/* ... through irq15 at vector 47 ... */
```

## 5. Handling IRQs in C

```c
/* kernel/irq.c — IRQ dispatch */

#include "irq.h"
#include "pic.h"
#include "vga.h"

/* Array of registered IRQ handlers: */
static irq_handler_fn irq_handlers[16];

/* Register a handler for an IRQ (0-15): */
void irq_register(uint8_t irq, irq_handler_fn handler) {
    irq_handlers[irq] = handler;
}

/* Called from the IRQ assembly stubs: */
void irq_handler(registers_t *regs) {
    /* IRQ number = vector - 32: */
    uint8_t irq = regs->int_no - 32;
    
    /* Call the registered handler (if any): */
    if (irq_handlers[irq]) {
        irq_handlers[irq](regs);
    }
    
    /* Send EOI (End of Interrupt) to PIC: */
    pic_eoi(irq);
}
```

```c
/* include/irq.h */
#pragma once
#include "isr.h"

typedef void (*irq_handler_fn)(registers_t *regs);

void irq_register(uint8_t irq, irq_handler_fn handler);
void irq_handler(registers_t *regs);
```

## 6. The PIT — Programmable Interval Timer

The PIT (Intel 8253/8254) fires IRQ0 at a programmable rate. We use it as the system timer:

```c
/* kernel/timer.c — PIT driver */

#include "timer.h"
#include "irq.h"
#include "vga.h"
#include "io.h"

#define PIT_CMD   0x43
#define PIT_CH0   0x40

/* Input clock frequency (in Hz): */
#define PIT_BASE_FREQ  1193182

static volatile uint32_t ticks = 0;

static void timer_callback(registers_t *regs) {
    (void)regs;
    ticks++;
}

void timer_init(uint32_t hz) {
    /* Register our timer handler for IRQ0: */
    irq_register(0, timer_callback);
    
    /* Calculate divisor: divisor = PIT_BASE_FREQ / desired_hz */
    uint32_t divisor = PIT_BASE_FREQ / hz;
    if (divisor > 65535) divisor = 65535;
    
    /* Command: Channel 0, Access mode lobyte/hibyte, Mode 3 (square wave), binary */
    outb(PIT_CMD, 0x36);
    
    /* Send divisor low byte, then high byte: */
    outb(PIT_CH0, (uint8_t)(divisor & 0xFF));
    outb(PIT_CH0, (uint8_t)((divisor >> 8) & 0xFF));
    
    /* Unmask IRQ0: */
    pic_unmask_irq(0);
}

uint32_t timer_get_ticks(void) {
    return ticks;
}

void timer_sleep(uint32_t ms) {
    uint32_t target = ticks + (ms * 100 / 1000); /* assuming 100 Hz timer */
    while (ticks < target) {
        __asm__ volatile("hlt"); /* sleep until next interrupt */
    }
}
```

## 7. The Keyboard IRQ

A minimal keyboard handler for IRQ1 (we'll build the full driver in Chapter 60):

```c
/* kernel/keyboard.c — basic keyboard IRQ handler */

#include "keyboard.h"
#include "irq.h"
#include "vga.h"
#include "io.h"

#define KBD_DATA_PORT  0x60

/* Very basic US scancode set 1 → ASCII mapping: */
static const char scancode_map[128] = {
    0,   27,  '1', '2', '3', '4', '5', '6', '7', '8', '9', '0', '-', '=', '\b',
    '\t','q',  'w', 'e', 'r', 't', 'y', 'u', 'i', 'o', 'p', '[', ']', '\n',
    0,   'a',  's', 'd', 'f', 'g', 'h', 'j', 'k', 'l', ';', '\'','`',
    0,   '\\', 'z', 'x', 'c', 'v', 'b', 'n', 'm', ',', '.', '/', 0,
    '*', 0,   ' '
};

static void keyboard_callback(registers_t *regs) {
    (void)regs;
    
    uint8_t scancode = inb(KBD_DATA_PORT);
    
    /* Ignore key-release events (scancode bit 7 set): */
    if (scancode & 0x80) return;
    
    char c = (scancode < 128) ? scancode_map[scancode] : 0;
    if (c) {
        terminal_putchar(c);
    }
}

void keyboard_init(void) {
    irq_register(1, keyboard_callback);
    pic_unmask_irq(1);
}
```

## 8. EOI — End of Interrupt

The EOI (End of Interrupt) signal is critical. Without it, the PIC won't send any more interrupts of the same or lower priority:

```
PIC internal state machine:
  IRQ fires → PIC asserts INT line to CPU
  CPU acknowledges → PIC sets ISR (In-Service Register) bit
  Handler runs...
  WITHOUT EOI: PIC keeps ISR bit set → no new IRQs from that PIC
  WITH EOI:    PIC clears ISR bit → ready for next IRQ
  
For IRQ0-IRQ7 (Master PIC):
  outb(0x20, 0x20)    ← EOI to master only
  
For IRQ8-IRQ15 (Slave PIC):
  outb(0xA0, 0x20)    ← EOI to slave first
  outb(0x20, 0x20)    ← Then EOI to master (because slave is cascaded through master IRQ2)
```

## 9. Complete pic.h

```c
/* include/pic.h */
#pragma once
#include "stdint.h"

#define PIC1_OFFSET  32     /* IRQ0  → vector 32 */
#define PIC2_OFFSET  40     /* IRQ8  → vector 40 */

void pic_init(void);
void pic_eoi(uint8_t irq);
void pic_mask_irq(uint8_t irq);
void pic_unmask_irq(uint8_t irq);
void pic_disable(void);
```

**Putting it all together in `kernel_main`:**
```c
void kernel_main(uint32_t magic, uint32_t mbi_ptr) {
    terminal_init();
    
    kprintf("GDT... "); gdt_init(); kprintf("OK\n");
    kprintf("IDT... "); idt_init(); kprintf("OK\n");
    kprintf("PIC... "); pic_init(); kprintf("OK\n");
    
    /* Mask all IRQs first, then enable only what we need: */
    pic_disable();
    
    kprintf("Timer (100 Hz)... "); timer_init(100); kprintf("OK\n");
    kprintf("Keyboard... ");       keyboard_init(); kprintf("OK\n");
    
    kprintf("\nSystem ready. Type something!\n> ");
    
    /* Enable interrupts and wait: */
    __asm__ volatile("sti");
    for (;;) {
        __asm__ volatile("hlt");  /* sleep until next interrupt */
    }
}
```

You should now see a prompt and be able to type characters on the screen using your keyboard!

## Summary

| Concept | Description |
|---------|------------|
| IRQ | Hardware interrupt request: asynchronous signal from device to CPU |
| 8259 PIC | Interrupt controller chip; chains 16 IRQs; master (IRQ0-7) + slave (IRQ8-15) |
| PIC remapping | IRQs must be remapped to vectors 32-47 to avoid collision with CPU exceptions 0-31 |
| ICW1-4 | Initialization Command Words: sequence of 4 bytes to configure the PIC |
| EOI | End of Interrupt: must send 0x20 to port 0x20 (and 0xA0 for slave) after each IRQ |
| Masking | Each IRQ can be individually enabled/disabled via data port bitmask |
| PIT | Programmable Interval Timer; fires IRQ0 at programmable rate; we use 100 Hz |
| PIT divisor | Divisor = 1193182 / desired_hz; 100 Hz → divisor = 11932 |
| IRQ0 | Timer interrupt — fundamental for preemptive multitasking |
| IRQ1 | Keyboard interrupt — scancode in port 0x60 |
| irq_handler | C function called from assembly stub; dispatches to registered handler, sends EOI |
| hlt | Halt instruction — CPU sleeps until next interrupt; good for idle loop |
| pic_disable() | Mask all IRQs; useful during initialization before individual unmasks |
