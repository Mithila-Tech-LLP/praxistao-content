# Machine Learning & AI: From Zero to Building Your Own AI
### For absolute beginners — if you have never heard of AI before, start here

> **Who is this for?** Anyone. Literally anyone. You do not need to know how to code. You do not need to be good at maths. You do not need a computer science degree. If you are a 15-year-old who has just heard the word "AI" and wants to know what it actually means — this is for you. If you are a working professional who uses ChatGPT every day but has no idea how it works — this is for you too.
>
> By the end of this course, you will have built your own small language model (like a tiny version of ChatGPT), your own AI agent (a program that can browse the web and take actions), and a real production AI system. You will understand not just how to *use* AI tools, but how they work from the ground up.

---

## What You Will Build

- **Your own language model** — a tiny GPT, trained from scratch, that generates text
- **An AI agent** — a program that searches the web, reads files, and solves problems on its own
- **A RAG chatbot** — an AI that answers questions about any document you give it
- **A production AI system** — complete with memory, tools, and a web interface
- **Claude Code integrations** — use AI as a professional coding partner

## How to Use This Course

### If you have never coded before:
Start at Chapter 00. Read every word. **Type** every code example yourself — do not copy-paste. Do the exercises before moving on. Do not skip chapters.

### If you know Python but not ML:
Skim Chapters 00-04. Start carefully from Chapter 08.

### If you know classical ML but not deep learning:
Jump to Chapter 15 (neural networks).

### If you want to build agents now:
Read Chapter 00, then Chapters 32, 37, 45, then jump to Part 8 (Chapter 39+).
