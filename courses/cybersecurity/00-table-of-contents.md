# Cybersecurity and Ethical Hacking — Complete Course
### From Zero to Ethical Hacker — Tools, Exploitation, Defense, and Building GoShield EDR in Go

## From Zero to Security Expert

*A complete curriculum: absolute beginner → professional cybersecurity practitioner. Every offensive technique is paired with defensive countermeasures. The GoShield project builds a real enterprise EDR from scratch.*

---

## Course Philosophy

1. **Learn by building** — every concept is accompanied by working Go code
2. **Offense informs defense** — understanding attacks makes you a better defender
3. **Go as the primary language** — single static binaries, goroutines for concurrency, production-grade tools
4. **Real enterprise project** — GoShield EDR mirrors production systems like CrowdStrike, SentinelOne, Palo Alto Cortex
5. **All content is for authorized learning only** — practice only on systems you own or have permission to test

## GoShield Project Architecture

GoShield is an enterprise EDR comparable to commercial products:

```
┌─────────────────────────────────────────────────────────────┐
│                      GoShield EDR                            │
│                                                             │
│  ┌──────────────────────┐     ┌─────────────────────────┐  │
│  │  Agent (per host)    │     │  Central Server          │  │
│  │                      │     │                         │  │
│  │  File Monitor        │     │  REST API               │  │
│  │   - fsnotify         │────▶│  Event Ingestion        │  │
│  │   - SHA256 hashing   │     │  Detection Engine       │  │
│  │   - YAML rules       │     │  SQLite + WAL           │  │
│  │                      │     │  Web Dashboard          │  │
│  │  Process Monitor     │     │  Slack/Email Alerts     │  │
│  │   - gopsutil         │     │                         │  │
│  │   - process tree     │     │  Deployment:            │  │
│  │   - injection detect │     │   Docker + Nginx        │  │
│  │                      │     │   TLS termination       │  │
│  │  Network Monitor     │     │                         │  │
│  │   - connection diff  │     └─────────────────────────┘  │
│  │   - DNS resolution   │                                   │
│  │   - beaconing detect │  1000s of agents via             │
│  │                      │  Ansible mass deployment         │
│  └──────────────────────┘                                   │
└─────────────────────────────────────────────────────────────┘
```

**Tech stack:**
- Language: Go 1.22
- Agent libraries: `fsnotify`, `gopsutil/v3`
- Server: `gorilla/mux`, `database/sql` + SQLite (WAL mode)
- Rules: YAML-based Sigma-like detection engine with sliding window thresholds
- Dashboard: Single-page HTML/CSS/JS, no frontend framework
- Deployment: Docker Compose + Nginx + systemd + Ansible
