## 1. What Is an Application?

An **application** (app) is a software program designed to help a user perform a specific task.

```
Tasks you do and the apps for them:

  Write a document        → Microsoft Word, Google Docs
  Browse the internet     → Chrome, Safari, Firefox
  Watch videos            → YouTube, Netflix, VLC
  Listen to music         → Spotify, Apple Music
  Send messages           → WhatsApp, iMessage, Slack
  Edit photos             → Lightroom, Snapseed, Photos
  Play games              → literally millions of games
  Track finances          → Excel, QuickBooks, Mint
  Learn a language        → Duolingo
  Navigate                → Google Maps, Apple Maps
  Shop                    → Amazon, your local store's app
```

Every app is designed with a specific purpose. Apps make the computer useful for everyday life.

## 4. Browsers — The App You Use Most

The **web browser** is probably the most-used application on any computer. It lets you visit websites on the internet.

```
Popular browsers:
  Chrome (Google)    → 65% market share, fast, syncs with Google account
  Safari (Apple)     → default on iPhone/Mac, very battery-efficient
  Firefox (Mozilla)  → privacy-focused, open source
  Edge (Microsoft)   → Windows default, built on same engine as Chrome
  Brave              → very privacy-focused, blocks ads by default
  
What a browser does:
  1. You type a web address (URL): google.com
  2. Browser contacts Google's server over the internet
  3. Server sends back the website's code (HTML/CSS/JavaScript)
  4. Browser reads the code and draws the web page on screen
  5. You see the website
  
Browser features:
  Tabs          → multiple websites open at once
  Bookmarks     → save favorite websites
  History       → list of websites you've visited
  Extensions    → add-ons that enhance the browser (ad blockers, password managers)
  Developer tools → for programmers to inspect websites
```

## 8. Web Apps vs. Native Apps

```
Native App:
  Installed on your device
  Works without internet (mostly)
  Can use all device features (camera, GPS, notifications)
  Fast, fluid experience
  Example: iPhone's Mail app, desktop Spotify
  
Web App:
  Runs in your browser, no installation
  Requires internet
  Works on any device with a browser
  Example: Gmail.com, Google Docs, Figma
  
Progressive Web App (PWA):
  A website that can be "installed" like an app
  Saves to your home screen
  Can work offline sometimes
  Example: Twitter PWA, Starbucks app
```

## 9. Installing and Uninstalling Apps

```
Installing on Windows:
  Download .exe or .msi from official website → run it
  Or: Microsoft Store → search → Install
  
Installing on Mac:
  Download .dmg from website → open → drag to Applications folder
  Or: Mac App Store → search → Get/Buy
  
Installing on iPhone:
  App Store → search → Get → confirm with Face ID/password
  
Installing on Android:
  Google Play Store → search → Install
  Or: download .apk file (less safe)
  
Uninstalling on Windows:
  Settings → Apps → Find app → Uninstall
  
Uninstalling on Mac:
  Drag app from Applications to Trash
  (Or use AppCleaner to remove all associated files too)
  
Uninstalling on phone:
  Long press app icon → Remove/Uninstall
```

**Safety tip:** Only install apps from official sources (App Store, Play Store, official websites of well-known companies). Downloading apps from random websites is a common way people get malware.
