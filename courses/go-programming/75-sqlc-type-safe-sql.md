# Chapter 52: SQLC — Type-Safe SQL

`sqlc` compiles SQL queries into type-safe Go code. Instead of writing `db.QueryRowContext` and manually mapping results, you write plain SQL and `sqlc` generates the Go structs, parameter types, and query functions. The result: compile-time SQL errors, zero runtime reflection, and no ORM magic.

## 1. Why sqlc

| | raw sql/sqlx | sqlc | ORM (GORM) |
|--|--------------|------|------------|
| SQL visible | Yes | Yes | No |
| Type safe | Partial | Yes (compile-time) | Partial |
| Code gen | No | Yes | No |
| Complex queries | Easy | Easy | Hard |
| Learning curve | Low | Low | Medium |
| N+1 prevention | Manual | Manual | Complicated |
| Performance | Excellent | Excellent | Overhead |

**sqlc sweet spot**: you want to write SQL (full control over queries, indexes, CTEs) but you also want Go types generated automatically instead of maintaining manual struct mappings.

## 2. Setup and Configuration

```bash
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
```

```yaml
# sqlc.yaml
version: "2"
sql:
  - engine: "postgresql"
    queries: "queries/"
    schema: "migrations/"
    gen:
      go:
        package: "db"
        out: "internal/db"
        emit_json_tags: true
        emit_db_tags: true
        emit_interface: true           # Generates Querier interface
        emit_exact_table_names: false
        emit_empty_slices: true
        emit_pointers_for_null_types: true  # *string for nullable columns
        overrides:
```

## 3. Writing Queries

Each query has a `-- name: QueryName :returnType` annotation.

```sql
-- queries/users.sql

-- name: CreateUser :one
INSERT INTO users (name, email, password_hash)
VALUES ($1, $2, $3)
RETURNING *;

-- name: GetUserByEmail :one
SELECT * FROM users WHERE email = $1;

-- name: GetUserByID :one
SELECT * FROM users WHERE id = $1;

-- name: UpdateUser :one
UPDATE users
SET name = $1, updated_at = NOW()
WHERE id = $2
RETURNING *;

-- name: DeleteUser :exec
DELETE FROM users WHERE id = $1;

-- name: ListUsers :many
SELECT * FROM users
ORDER BY created_at DESC
LIMIT $1 OFFSET $2;

-- name: CountUsers :one
SELECT COUNT(*) FROM users;
```

```sql
-- queries/notes.sql

-- name: CreateNote :one
INSERT INTO notes (owner_id, title, content)
VALUES ($1, $2, $3)
RETURNING *;

-- name: GetNoteByID :one
SELECT * FROM notes
WHERE id = $1 AND deleted_at IS NULL;

-- name: GetNoteForOwner :one
SELECT * FROM notes
WHERE id = $1 AND owner_id = $2 AND deleted_at IS NULL;

-- name: ListNotesByOwner :many
SELECT * FROM notes
WHERE owner_id = $1 AND deleted_at IS NULL
ORDER BY updated_at DESC
LIMIT $2 OFFSET $3;

-- name: CountNotesByOwner :one
SELECT COUNT(*) FROM notes
WHERE owner_id = $1 AND deleted_at IS NULL;

-- name: UpdateNote :one
UPDATE notes
SET
    title = COALESCE(NULLIF(sqlc.narg(title), ''), title),
    content = COALESCE(NULLIF(sqlc.narg(content), ''), content),
    version = version + 1,
    updated_at = NOW()
WHERE id = sqlc.arg(id)
  AND owner_id = sqlc.arg(owner_id)
  AND version = sqlc.arg(version)
  AND deleted_at IS NULL
RETURNING *;

-- name: SoftDeleteNote :exec
UPDATE notes SET deleted_at = NOW() WHERE id = $1 AND owner_id = $2;

-- name: SearchNotes :many
SELECT *, ts_rank(search_vector, plainto_tsquery('english', $2)) AS rank
FROM notes
WHERE owner_id = $1
  AND deleted_at IS NULL
  AND search_vector @@ plainto_tsquery('english', $2)
ORDER BY rank DESC
LIMIT 20;

-- name: GetNoteWithTags :many
SELECT
    n.*,
    t.id   AS tag_id,
    t.name AS tag_name,
    t.color AS tag_color
FROM notes n
LEFT JOIN note_tags nt ON nt.note_id = n.id
LEFT JOIN tags t       ON t.id = nt.tag_id
WHERE n.id = $1 AND n.deleted_at IS NULL;
```

## 4. Generated Code Patterns

sqlc generates code like this (you never edit it):

```go
// internal/db/models.go — generated
package db

import "time"

type User struct {
    ID           int64     `db:"id"    json:"id"`
    Name         string    `db:"name"  json:"name"`
    Email        string    `db:"email" json:"email"`
    PasswordHash string    `db:"password_hash" json:"-"`
    CreatedAt    time.Time `db:"created_at" json:"createdAt"`
    UpdatedAt    time.Time `db:"updated_at" json:"updatedAt"`
}

type Note struct {
    ID        int64      `db:"id"        json:"id"`
    OwnerID   int64      `db:"owner_id"  json:"ownerId"`
    Title     string     `db:"title"     json:"title"`
    Content   string     `db:"content"   json:"content"`
    Status    string     `db:"status"    json:"status"`
    Version   int32      `db:"version"   json:"version"`
    DeletedAt *time.Time `db:"deleted_at" json:"deletedAt,omitempty"`
    CreatedAt time.Time  `db:"created_at" json:"createdAt"`
    UpdatedAt time.Time  `db:"updated_at" json:"updatedAt"`
}
```

```go
// internal/db/users.sql.go — generated
package db

const createUser = `
INSERT INTO users (name, email, password_hash)
VALUES ($1, $2, $3)
RETURNING id, name, email, password_hash, created_at, updated_at`

type CreateUserParams struct {
    Name         string
    Email        string
    PasswordHash string
}

func (q *Queries) CreateUser(ctx context.Context, arg CreateUserParams) (User, error) {
    row := q.db.QueryRowContext(ctx, createUser, arg.Name, arg.Email, arg.PasswordHash)
    var u User
    err := row.Scan(&u.ID, &u.Name, &u.Email, &u.PasswordHash, &u.CreatedAt, &u.UpdatedAt)
    return u, err
}

// Querier interface — generated:
type Querier interface {
    CreateUser(ctx context.Context, arg CreateUserParams) (User, error)
    GetUserByEmail(ctx context.Context, email string) (User, error)
    GetUserByID(ctx context.Context, id int64) (User, error)
    // ... all query methods
}
```

### Using Generated Queries

```go
package store

import (
    "context"
    "database/sql"
    "errors"

    "github.com/jmoiron/sqlx"

    "myapp/internal/db"
)

type UserStore struct {
    q *db.Queries
}

func NewUserStore(database *sqlx.DB) *UserStore {
    return &UserStore{q: db.New(database)}
}

func (s *UserStore) Create(ctx context.Context, name, email, passwordHash string) (*db.User, error) {
    u, err := s.q.CreateUser(ctx, db.CreateUserParams{
        Name: name, Email: email, PasswordHash: passwordHash,
    })
    if err != nil {
        if isUniqueViolation(err) { return nil, ErrEmailTaken }
        return nil, fmt.Errorf("create user: %w", err)
    }
    return &u, nil
}

func (s *UserStore) GetByEmail(ctx context.Context, email string) (*db.User, error) {
    u, err := s.q.GetUserByEmail(ctx, email)
    if errors.Is(err, sql.ErrNoRows) { return nil, ErrNotFound }
    if err != nil { return nil, fmt.Errorf("get user by email: %w", err) }
    return &u, nil
}

func isUniqueViolation(err error) bool {
    var pqErr *pq.Error
    return errors.As(err, &pqErr) && pqErr.Code == "23505"
}
```

## 5. Advanced Queries

### CTEs and Window Functions
```sql
-- name: GetUserStats :one
WITH user_notes AS (
    SELECT owner_id, COUNT(*) AS total_notes,
           SUM(LENGTH(content)) AS total_chars
    FROM notes
    WHERE deleted_at IS NULL
    GROUP BY owner_id
)
SELECT
    u.*,
    COALESCE(un.total_notes, 0) AS total_notes,
    COALESCE(un.total_chars, 0) AS total_chars,
    RANK() OVER (ORDER BY COALESCE(un.total_notes, 0) DESC) AS notes_rank
FROM users u
LEFT JOIN user_notes un ON un.owner_id = u.id
WHERE u.id = $1;

-- name: GetRecentActivity :many
SELECT
    'note_created' AS event_type,
    n.id AS resource_id,
    n.title AS resource_name,
    n.created_at AS occurred_at
FROM notes n
WHERE n.owner_id = $1
UNION ALL
SELECT
    'tag_added',
    t.id,
    t.name,
    nt.created_at
FROM tags t
JOIN note_tags nt ON nt.tag_id = t.id
JOIN notes n ON n.id = nt.note_id
WHERE n.owner_id = $1
ORDER BY occurred_at DESC
LIMIT 20;
```

### Batch Inserts
```sql
-- name: BatchCreateNotes :batchone
INSERT INTO notes (owner_id, title, content)
VALUES ($1, $2, $3)
RETURNING *;
```

```go
// sqlc batch — runs multiple inserts with a single round trip:
batch := s.q.BatchCreateNotes(ctx, []db.BatchCreateNotesParams{
    {OwnerID: 1, Title: "Note 1", Content: "..."},
    {OwnerID: 1, Title: "Note 2", Content: "..."},
})
batch.Query(func(i int, note db.Note, err error) {
    if err != nil { log.Printf("batch insert %d failed: %v", i, err) }
})
if err := batch.Close(); err != nil { ... }
```

### Dynamic Filters
```sql
-- Dynamic filters are tricky with sqlc. Use multiple queries or a pattern:

-- name: ListNotesFiltered :many
SELECT * FROM notes
WHERE owner_id = $1
  AND ($2::text IS NULL OR status = $2)
  AND ($3::text IS NULL OR search_vector @@ plainto_tsquery('english', $3))
  AND deleted_at IS NULL
ORDER BY updated_at DESC
LIMIT $4 OFFSET $5;
```

## 6. Testing with sqlc

```go
// Use testcontainers for an isolated Postgres per test:
// go get github.com/testcontainers/testcontainers-go

func setupTestDB(t *testing.T) *sqlx.DB {
    t.Helper()

    ctx := context.Background()
    req := testcontainers.ContainerRequest{
        Image:        "postgres:16-alpine",
        ExposedPorts: []string{"5432/tcp"},
        Env: map[string]string{
            "POSTGRES_PASSWORD": "test",
            "POSTGRES_DB":       "testdb",
        },
        WaitingFor: wait.ForListeningPort("5432/tcp"),
    }
    container, err := testcontainers.GenericContainer(ctx, testcontainers.GenericContainerRequest{
        ContainerRequest: req, Started: true,
    })
    require.NoError(t, err)
    t.Cleanup(func() { container.Terminate(ctx) })

    host, _ := container.Host(ctx)
    port, _ := container.MappedPort(ctx, "5432")
    dsn := fmt.Sprintf("postgres://postgres:test@%s:%s/testdb?sslmode=disable", host, port.Port())

    sqlDB, err := sqlx.Connect("postgres", dsn)
    require.NoError(t, err)
    t.Cleanup(func() { sqlDB.Close() })

    // Run migrations:
    require.NoError(t, store.RunMigrations(dsn, "../../migrations"))
    return sqlDB
}

func TestUserStore(t *testing.T) {
    sqlDB := setupTestDB(t)
    store := store.NewUserStore(sqlDB)

    t.Run("create and get", func(t *testing.T) {
        u, err := store.Create(context.Background(), "Alice", "alice@test.com", "hashed")
        require.NoError(t, err)
        assert.Equal(t, "Alice", u.Name)
        assert.Greater(t, u.ID, int64(0))

        got, err := store.GetByEmail(context.Background(), "alice@test.com")
        require.NoError(t, err)
        assert.Equal(t, u.ID, got.ID)
    })

    t.Run("duplicate email returns ErrEmailTaken", func(t *testing.T) {
        store.Create(context.Background(), "Alice", "dup@test.com", "h")
        _, err := store.Create(context.Background(), "Alice2", "dup@test.com", "h")
        assert.ErrorIs(t, err, store.ErrEmailTaken)
    })
}
```

## Summary

- `sqlc` compiles SQL → Go: type-safe params, auto-generated structs, no manual scanning
- Write queries in `.sql` files with `-- name: QueryName :returnType` annotations
- Return types: `:one` (single row), `:many` (slice), `:exec` (no rows), `:batchone` (batch insert)
- `sqlc.narg(col)` generates a nullable parameter; `sqlc.arg(name)` for named params
- Generated `Querier` interface enables mocking in tests
- Use `testcontainers-go` for real Postgres in tests — no mocks for DB code
- `sqlc vet` catches SQL errors at build time; faster feedback than runtime errors

## Exercises

### Easy
1. Set up `sqlc` for the notes project. Write queries for the `tags` table: `CreateTag`, `GetTagByID`, `ListTagsByOwner`, `DeleteTag`. Run `sqlc generate` and verify the generated code compiles.
2. Write a `GetNoteWithTagCount` query using a subquery: `SELECT n.*, (SELECT COUNT(*) FROM note_tags nt WHERE nt.note_id = n.id) AS tag_count FROM notes n WHERE n.id = $1`. Add `TagCount int32` to a custom result struct (use `sqlc.embed` or handle in Go).
3. Write a query `ListRecentlyEditedByUser` that returns the 5 most recently updated notes for a user, including only `id`, `title`, and `updated_at`. Verify the generated params and result struct are exactly as expected.

### Medium
4. Implement **`UpdateNoteStatus`**: `UPDATE notes SET status = $1, updated_at = NOW() WHERE id = $2 AND owner_id = $3 AND status != $1 RETURNING *`. Add a check constraint in the migration that only allows transitions: `draft → published`, `published → archived`, `archived → draft`. The constraint lives in SQL, not Go.
5. Write a **search query with highlighting**: use `ts_headline('english', content, plainto_tsquery('english', $2))` to return the relevant content snippet with query terms highlighted. Return both the rank and the headline. Test that the headline wraps matching terms in `<b>...</b>` tags.
6. Write a complex **JOIN query** for the dashboard: return each note with its owner's name and an array of tag names. Use `jsonb_agg` to aggregate tags into a JSON array: `SELECT n.*, u.name AS owner_name, jsonb_agg(t.name) FILTER (WHERE t.id IS NOT NULL) AS tag_names FROM notes n JOIN users u ON u.id = n.owner_id LEFT JOIN note_tags nt ON nt.note_id = n.id LEFT JOIN tags t ON t.id = nt.tag_id GROUP BY n.id, u.name`. Map the JSON array to `[]string` in Go.

### Hard
7. Build a **migration testing tool** using sqlc: after running `sqlc generate`, write a test that verifies every query in the `Querier` interface can be executed without SQL errors (use `EXPLAIN` to validate without touching data). This catches query-schema drift between migrations and queries.
8. Implement a **generic repository** on top of sqlc: since sqlc generates a `Querier` interface, write a `Repository[T]` that wraps it and adds: cache (in-memory LRU from Ch 33), metrics (query latency histogram), and retry (3 attempts on connection errors). The generic type T constrains to types that have an `ID int64` field. Show that `UserRepository` and `NoteRepository` both use the same `Repository` base.
