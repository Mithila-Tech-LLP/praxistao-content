Before touching a single API or database, get comfortable with Go itself — its syntax, its tooling, and the way it wants you to structure a program. Nothing here is backend-specific yet; it's the vocabulary everything else is written in.

### Why Go for Backend Engineering
Go was built at Google specifically for the problems backend systems run into: too many engineers, too much code, and servers that need to handle thousands of things at once. Understand what makes it different from languages like Python or Java before you write a line of it.

**Resources:**
- [What Is Go and Why Learn It](course:go-programming#01-what-is-go-and-why-learn-it)

### Set Up Your Go Environment
Install Go, set up your editor, and understand `go mod` — the module system every Go project is built on.

This is where Go starts to feel like Go. Functions are values, structs are how you model data, and interfaces are how Go does polymorphism without classes.
