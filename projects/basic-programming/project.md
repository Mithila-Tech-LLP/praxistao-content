## Overview

This project is your first step into hands-on programming. Instead of following a tutorial, you will write real code that is automatically tested against a predefined test suite.

Each task is small and focused — most take 5–15 minutes. The challenge is not complexity but precision: the computer follows your instructions exactly, so every edge case matters.

By the end you will have solved 10 classic programming problems, all verified by real tests running on your machine.

## Who Should Take This

- Anyone who has read through a basic programming course and wants to apply what they learned
- People who learn best by doing, not just reading
- Beginners who want their first taste of test-driven development

## How It Works

1. Install the `lncli` CLI tool
2. Run `lncli init --project basic-programming` — this creates a local project folder with starter code and tests for all tasks
3. Edit the starter code in your editor of choice
4. Run `lncli run` inside the project folder to execute tests
5. When all tests for the current task pass, the CLI updates your progress, commits, and pushes to GitHub
6. Come back here and click **Check Progress** to unlock the next task
