## Overview

Data structures are the vocabulary of computer science. Every algorithm you write — sorting, searching, caching, routing — rests on one or more of them. In this project you will implement 10 of the most important ones from scratch in Go.

You will not use any built-in container types. Each task gives you the interface (the struct and method signatures) and you build the internals. Tests verify correctness across edge cases.

## Who Should Take This

You understand Go structs, interfaces, and pointers. You want to deeply understand how data structures work, not just how to use them.
